# OpenCode Mobile 0.2.0-debug — плагины (MCP) и защита opencode.json

Неофициальный Android-клиент OpenCode (не продукт команды OpenCode).
Пакет: `ru.dredd20.opencode`. versionName **0.2.0**, versionCode **10**.
Подпись: тот же debug-сертификат, что у 0.1.0–0.1.3
(SHA-256 `65b96eb07abe416771b1a8c96184d87641d2e1cf51954ec340d40d34b32d2a90`). Ключа в репозитории нет.
Ветка `feature/plugins` от `2c91a6c` (0.1.3). Основание: `/workspace/opencode-study/PLUGINS.md`, этапы 0 и 1.

## Этап 0. opencode.json больше не затирается

- `runtime/OpenCodeConfig.kt` (чистая логика + атомарная запись 0600). Приложение владеет только ключами
  `update: "disable"` и `mcp.servers.phone` (`type: local`, `command: ["phone-mcp"]`).
- `GuestFiles.writeOpenCodeConfig()` (Setup и повторная установка CLI) теперь делает merge. Дополнительно merge
  вызывается при каждом старте встроенного сервера (`RuntimeService.startServer`), файл пишется только если что-то
  поменялось.
- Пользовательские `mcp.servers.*`, `plugins`, `provider`, `model`, `$schema` и прочие ключи сохраняются. У `phone`
  обновляются только наши поля, пользовательские (`disabled`, `timeout`) остаются; `url/headers/oauth` у `phone`
  удаляются (иначе конфиг невалиден).
- Пустой/отсутствующий файл → шаблон. Битый JSON (или не объект) → старый текст в
  `opencode.json.broken-<ms>.bak` (0600), в `install.log` строка без содержимого, затем шаблон.

## Этап 1. Экран «Плагины»

Новые файлы: `plugins/Registry.kt`, `plugins/McpApi.kt`, `plugins/Installed.kt`, `plugins/PluginsController.kt`,
`ui/PluginsScreen.kt`. Вход: значок пазла в верхней панели сессии и кнопка «Открыть «Плагины»» в настройках
приложения (раздел «Плагины (MCP)» над «Доступы телефона»; раздел «Обновления приложения» не менялся).

- **Каталог.** `https://registry.modelcontextprotocol.io/v0.1/servers?version=latest&limit=50`, курсорная пагинация
  («Загрузить ещё»), поиск на стороне реестра (от 3 символов, короче — локальный фильтр), задержка 400 мс при вводе.
  Удалённые (`status: deleted`) и дубликаты скрыты. Все увиденные записи кэшируются в
  `files/plugins/registry-cache.json` (до 3000). Нет сети → «Офлайн: показан сохранённый каталог (время)»,
  поиск по кэшу локально.
- **Фильтр.** Устанавливаются только `remotes[].type == "streamable-http"` с обычным `https://` URL без шаблонов.
  Остальное «недоступно пока» с причиной: npx/Node, uvx/PyPI, Docker (oci), SSE-only (в OpenCode 2.3 клиента SSE
  нет), URL с `{параметрами}`. Переключатель «Только доступные на телефоне» (по умолчанию вкл.).
- **Карточка.** Название, имя в реестре, версия, описание, транспорты и пакеты, сайт. Поле «Имя в opencode.json»
  (латиница/цифры/`-`/`_`, уникальное, не `phone`). Поля для заголовков из реестра, секретные замаскированы
  (кнопка «Показать»), обязательные проверяются. Предупреждение о стороннем сервере.
- **Установка в один тап.** Запись `mcp.servers.<имя> = {type: remote, url, headers?}` (oauth не трогаем, чтобы
  OAuth-серверы получили статус «нужен вход») + `PUT /api/experimental/mcp/<имя>` с телом `{"config": …}` для
  локации по умолчанию и всех загруженных (`GET /api/debug/location`): PUT действует на одну локацию и только до
  рестарта. Если сервер не запущен, запись сохраняется и подключится при старте.
- **Установленные.** Конфиг + `GET /api/mcp`. Пустой ответ сразу после старта → «ожидание» и опрос раз в 2 с
  (до 40 с), а не ошибка. Статусы: подключён / нужен вход / ошибка / выключен / подключается. Заголовки показываются
  только именами («Authorization (••••)»). Сервер не отвечает → показ конфига с пометкой.
- **Удаление** с подтверждением: из `opencode.json` + `DELETE /api/experimental/mcp/<имя>` во всех локациях.
- **«Войти»** (для `needs_auth`) и ссылка внизу открывают веб-UI на `/settings?tab=extensions&subtab=mcps`
  (Настройки → Расширения → МКП с кнопкой «Sign in to …»). Custom Tabs — этап 2, не делался.
- **phone** — «Телефон (phone)», встроенный, без кнопки «Удалить»; `putServer/removeServer` его не трогают.
- **Termux / удалённый сервер:** конфиг не наш, установка только через PUT до рестарта, на экране пояснение.
- Секреты: значения заголовков только в `opencode.json` (0600) в private storage; в `svc.log` пишется лишь
  `plugins: install <реестр> as <имя> (headers: <имена>) api=ok`.
- Планшет (ширина Expanded): слева вкладки и список, справа карточка.
